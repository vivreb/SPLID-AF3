# SPLID-AF3

Welcome to the GitHub repository related to SPLID-AF3 (publication link will follow once available). Here I document all code needed to generate and evaluate the structural predictions that were presented in the manuscript.

## What is SPLID-AF3?

We use a split-domain approach to generate structural predictions to predict kinase propensity towards allosteric structural rearrangements upon binding of an ATP-competitive inhibitor, which we observed in our previous work (see https://doi.org/10.1038/s44320-026-00229-2). We first generate AlphaFold3 predictions for kinases in apo and staurosporine-bound states, and then generated measures to classify whether each kinase is likely to undergo such rearrangements.

## How to set up AlphaFold3 predictions

All relevant code and documents are in the folder "01_setup_predictions".

The predictions were run on the ETH Euler cluster (see https://docs.hpc.ethz.ch/software/chemistry/alphafold3/ and https://github.com/jurgjn/batch-infer). First, the necessary input .json files and all other folders and configuration files were generated by running "setup_files_for_alphafold_predictions.R". Jobs were submitted using "setup_jobs_script.py". Note that other computer infrastructure will require a different setup.

## Evaluating AlphaFold3 predictions

All relevant code and documents are in the folder "02_evaluate_predictions".

First, python preprocessing scrips are run in the labelled order (1-5). This results in sorted files in the correct format needed for the evaluation. Finally, the analysis is completed in R to calculate pairwise distances, RMSSD and dSASA.
